So this is my favorite project by far for the time being.
I loved every single bit of it and hope to repeat something like that again next year.

This was overall a humanoid robot Hatsune Miku designed to sing and dance for enterntainment.

The Robot frame is built from Aluminium beams.
Rough material overview:
  Raspberry Pi Model 3B+
  Raspberry Pi Pico (RP2040)
  20000mAh Powerbank
  Batérie 18650, 3.7V, 2500mAh
  CUQI 7 Inch Mini Monitor HD IPS 1024 x 600 HDMI Display Touchscreen for Raspberry Pi 3/4/5, PC, Windows, Xbox, Camera
  Breadboard, Perfboard
  WaveShare MG996R Servomotor
  Motor s prevodovkou 25GA-370 12V
  H Mostik - BTS7960B DC 43A
  Custom 3D vytlačené ruky, podstava, hlava (krabica)
